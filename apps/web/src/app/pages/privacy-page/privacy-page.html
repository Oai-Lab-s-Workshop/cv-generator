Politique de confidentialité

Comment Resumate traite, héberge et protège vos données personnelles selon que vous utilisez la version web hébergée ou une version desktop / auto-hébergée.

Version web

Hébergée

Accès soumis à un abonnement via Stripe

Version desktop

Locale

Utilisation autonome, vendue ou open source selon la distribution

1. Responsable

Responsable du traitement

Pour la version web hébergée, le traitement des données personnelles est effectué dans le cadre du service Resumate accessible en ligne. Pour la version desktop ou auto-hébergée, l'exploitant de l'instance ou l'utilisateur qui l'installe sur sa propre infrastructure devient responsable du traitement pour les données qu'il stocke et administre.

2. Données

Données collectées

Resumate traite les données que vous fournissez volontairement dans l'application, notamment :

  • Informations de profil et de contact
  • CV, profils professionnels et contenus rédactionnels associés
  • Expériences, projets, formations, compétences, réalisations et loisirs
  • Fichiers téléversés comme les photos ou autres assets liés au CV
  • Dans la version web hébergée, les informations de facturation strictement nécessaires à la gestion de l'abonnement, traitées via Stripe

3. Authentification

Cookies, session et stockage local

Resumate utilise le stockage local du navigateur pour conserver le token d'authentification nécessaire à l'utilisation de l'application. Aucun cookie publicitaire ou de suivi comportemental n'est utilisé dans le fonctionnement standard de l'application. Dans la version web hébergée, des traces techniques minimales peuvent être conservées pour sécuriser la session, gérer les accès et maintenir le service.

4. Base légale

Base légale du traitement

Le traitement repose sur l'exécution du service que vous utilisez, sur votre consentement lors de la création de votre compte lorsque cela est nécessaire, et sur l'intérêt légitime de sécuriser l'application, prévenir les abus et assurer la maintenance du service hébergé.

5. Conservation

Durée de conservation

Vos données sont conservées tant que votre compte ou votre instance reste active. Dans la version web hébergée, certaines données contractuelles ou comptables liées à la facturation peuvent être conservées plus longtemps pour répondre aux obligations légales applicables. Dans la version desktop / auto-hébergée, la durée de conservation dépend de l'administrateur de l'instance ou de vos propres choix si vous l'exploitez vous-même.

6. Sécurité

Mesures de sécurité

Resumate s'appuie sur PocketBase pour la gestion des comptes et des données applicatives. Les mots de passe sont hashés, les accès sont authentifiés, et les données de la version desktop ou auto-hébergée restent sur l'infrastructure choisie par l'utilisateur ou l'administrateur. Pour la version web hébergée, des mesures complémentaires d'administration, de journalisation technique et de maintenance peuvent être appliquées pour protéger le service.

7. Vos droits

Accès, rectification, portabilité et effacement

Selon votre contexte d'utilisation, vous disposez de droits sur vos données personnelles, notamment :

  • Droit d'accès : consulter les données qui vous concernent
  • Droit de rectification : corriger les informations inexactes
  • Droit à la portabilité : exporter vos données lorsqu'un export est disponible
  • Droit à l'effacement : demander la suppression de votre compte ou supprimer les données de votre instance selon le mode d'hébergement

8. Tiers et contact

Prestataires et contact

Dans la version web hébergée, Stripe peut intervenir comme prestataire de paiement pour la souscription et la gestion des abonnements. Dans la version desktop ou auto-hébergée, aucun prestataire de paiement n'est nécessaire sauf si vous en intégrez un vous-même. Pour toute question relative à la protection de vos données, vous pouvez consulter le dépôt GitHub du projet ou contacter l'administrateur de votre instance.
